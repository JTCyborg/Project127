# Project127 architecture

## 1. Назначение

Project127 — новая ATM/NeoGS host-система. Это не продолжение x86/BIOS-архитектуры Project126 и не перенос кода Project125.

## 2. Независимые ресурсы

| Ресурс | Объём | Владелец |
|---|---:|---|
| ATM RAM | 1 MiB | Z80 host |
| NeoGS RAM | 4 MiB | NeoGS subsystem |

Регионы памяти независимы. Нельзя считать NeoGS RAM продолжением ATM RAM или передавать адрес одного региона как указатель другого.

Все размеры, смещения, длины передач и файловые позиции в API — беззнаковые UINT32. Проверка переполнения обязательна до вычисления конечного адреса/смещения.

## 3. Владение устройствами

ATM host является владельцем внешних устройств и их портов. NeoGS не обращается к Nemo IDE, SMUC, RTC или другим внешним устройствам самостоятельно. Запросы NeoGS к host выполняются через явно определённый транспорт и DMA.

Физический накопитель — реальный Nemo IDE/SMUC. Обязательные операции host-драйвера: IDENTIFY, READ, WRITE, FLUSH. Обязательны проверки LBA, размера буфера, полного объёма передачи и границ ATM RAM. Образ TRD не является заменой HDD.

RTC: DS12887 через SMUC, обслуживается host.

## 4. Порядок реализации

1. Boot entry и диагностический канал.
2. Общий UINT32 range/check API и тесты границ.
3. ATM RAM page allocator и memory operations.
4. TR-DOS disk service — только загрузочный носитель и файловый сервис.
5. ATM native video service.
6. RTC service.
7. Keyboard/input service.
8. Nemo IDE/SMUC physical block storage.
9. Speaker/audio.
10. Timer/event service и interrupt/dispatch foundation.

Порядок может быть изменён только после фиксации причины и влияния на зависимости.

## 5. Контракт первого этапа

Первый этап не инициализирует память NeoGS, видео, RTC, клавиатуру или HDD. Он только:
- устанавливает безопасный стек;
- выдаёт диагностический маркер через порт #EF;
- остаётся в предсказуемом цикле.

Это отделяет проблему загрузки от ошибок будущих драйверов.
