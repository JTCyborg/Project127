# Project127 boot protocol

The generated 640 KiB TR-DOS image contains two files:

- BOOT — tokenized Spectrum BASIC loader.
- P127BOOT — assembled Z80 host entry loaded at #6000.

At the TR-DOS prompt, execute:

~~~text
RUN "BOOT"
~~~

The BASIC program executes CLEAR 24575, loads P127BOOT as CODE at decimal
24576 (#6000), then transfers control with RANDOMIZE USR 24576.
Its keyword tokens, line framing, end marker (#80), and TR-DOS run-line
marker (#AA, followed by line number 10 little-endian) are generated by
tools/trd_image.py.

The host entry initializes SP to #BFFF and writes P127 START and
P127 BOOT0 OK through debug port #EF.

Build on Windows with Python 3 and SjASMPlus on PATH:

~~~powershell
.\tools\build_project127.ps1
~~~

Output: build\Project127.trd. The image builder validates directory entries,
file extents, BASIC token presence, code load address, disk descriptor and
exact image length. This verifies the generated image format; actual ATM/TR-DOS
emulator execution still requires runtime confirmation.
