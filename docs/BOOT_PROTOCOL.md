# Project127 boot protocol

The generated 640 KiB TR-DOS image contains two files:

- `BOOT` — tokenized Spectrum BASIC loader.
- `P127BOOT` — assembled Z80 host entry loaded at #6000.

At the TR-DOS prompt, execute:

~~~text
RUN "BOOT"
~~~

The BASIC program executes `CLEAR 24575`, loads `P127BOOT` as CODE at
decimal 24576 (#6000), then transfers control with
`RANDOMIZE USR 24576`. Its keyword tokens, line framing, end marker (#80),
and TR-DOS run-line marker (#AA, followed by line number 10 little-endian)
are generated by `tools/trd_image.py`.

The host entry initializes SP to #BFFF and writes `P127 START` and
`P127 BOOT0 OK` through debug port #EF.

Build on Windows by double-clicking `build_project127.bat`. The script uses
the included `tools/sjasmplus.exe` and Python 3.

Outputs:

- `disk_A.trd` — ready-to-open 640 KiB TR-DOS image in the repository root.
- `build/disk_A.trd` — identical build copy.
- `build/p127_boot.bin` — assembled host entry.

The image builder validates the directory entries, file extents, BASIC tokens,
code load address, disk descriptor, exact image length and stored code bytes.
This verifies the generated image format; actual ATM/TR-DOS emulator execution
still requires runtime confirmation.
